# 视觉特效开发 Skill

参考《一念逍遥》的视觉设计理念，为文字修仙游戏提供沉浸式修仙视觉体验。

## 设计原则
- **水墨淡彩**：色调以淡彩为主，干净清透素雅，避免浓墨重彩
- **成长外显**：境界突破带来实质性视觉变化，玩家一眼看到成长
- **灵气流转**：修炼界面始终有灵气流动感，营造"修仙进行时"氛围

## 一、丹田可视化系统

### 各境界丹田形态

| 境界 | 丹田形态 | 实现方式 |
|------|---------|---------|
| 凡人 | 无丹田 | 空状态 |
| 炼气期 | 淡蓝气团，缓缓旋转，小境界越高气团越浓 | CSS radial-gradient + animation rotate |
| 筑基期 | 气团凝聚为液态球体，动态离散粒子 | CSS 多层渐变 + 粒子溢出 |
| 金丹期 | 固态金丹，金色光芒流转 | CSS 金色球体 + box-shadow 光晕 |
| 元婴期 | 金丹碎裂化为婴孩（蜷缩→直立→打坐三段） | CSS sprite / emoji 渐变过渡 |
| 化神期 | 婴孩成长为人形，周身光环 | 更大的人物 + 光环旋转 |
| 合体期 | 人形与光环融合，灵气爆棚 | 全屏灵气粒子密度增加 |
| 大乘期 | 金身法相显现 | 人物放大 + 金色边框光效 |
| 渡劫期 | 天雷环绕金身 | 闪电粒子 + 震动动画 |

### 丹田CSS参考
```css
/* 炼气期 - 气团 */
.dantian.qi { 
  background: radial-gradient(circle, rgba(100,150,255,0.6) 0%, rgba(100,150,255,0.1) 60%, transparent 100%);
  animation: breathe 3s ease-in-out infinite;
}
/* 金丹期 - 金丹 */
.dantian.golden-core {
  background: radial-gradient(circle, #ffd700 0%, #b8860b 40%, rgba(184,134,11,0.3) 70%, transparent 100%);
  box-shadow: 0 0 30px rgba(255,215,0,0.5), 0 0 60px rgba(255,215,0,0.2);
  animation: rotate 8s linear infinite, glow 2s ease-in-out infinite;
}
```

## 二、境界突破动画流程

突破动画分5个阶段（使用 GSAP Timeline）：

```
阶段1: 蓄力 (0-1s)     → 灵气汇聚，画面暗角加深，粒子加速旋转
阶段2: 冲击 (1-2s)     → 画面震动，核心爆发白光，口诀文字浮现
阶段3: 蜕变 (2-3.5s)   → 丹田形态切换，新境界特效渐入
阶段4: 天劫 (条件触发) → 闪电粒子密集出现，屏幕红闪
阶段5: 礼成 (3.5-5s)   → 金光降临，属性数值跳动增长，境界名大字浮现
```

## 三、修炼周天流光

修炼按钮周围应有灵气运转的视觉：
- 按钮外围 3-5 个光点沿椭圆轨道旋转
- 光点大小呼吸变化
- 颜色与灵根属性对应（金=金、木=绿、水=蓝、火=红、土=褐、风=青、雷=紫）
- 吐纳按钮居中，区分道修颜色（剑修暖色、灵修冷色、邪修暗红）

## 四、水墨质感UI规范

### 色调体系
- 背景：宣纸淡黄 / 米白底色 + 淡墨渲染
- 面板：半透明水墨晕染效果，边缘笔触不规则
- 文字：深墨色，标题用楷体/行书
- 按钮：水墨笔触描边 + 淡彩填充

### 笔触实现
```css
/* 水墨边框模拟 */
.ink-border {
  border: 2px solid;
  border-image: linear-gradient(90deg, transparent, #4a3728, #2a1a0a, #4a3728, transparent) 1;
  border-radius: 4px 16px 8px 12px; /* 不规则圆角模拟手工感 */
}
```

## 五、粒子系统分级

| 场景 | 粒子密度 | 粒子类型 |
|------|---------|---------|
| 修炼中枢 | 10-15个 | 慢速上升光点，颜色随灵根 |
| 突破动画 | 30-50个 | 快速汇聚+爆发扩散 |
| 天劫 | 20-30个 | 闪电型粒子，从上往下 |
| 战斗 | 5-10个 | 技能碰撞火花 |
